# Pre-recorded Liturgical Audio Directory

This directory hosts pre-recorded audio tracks (`.mp3`, `.m4a`, or `.opus`) for the invariant parts of the 1662 Book of Common Prayer.

When the Daily Office audio player is in **"Hybrid Mode"** (default):
- Any invariant section with a matching audio file in this directory is played directly using the recording (e.g. authentic Anglican choral chant, plainchant, or reverent human spoken prayer).
- Changing sections (the **Psalms of the Day**, **First Lesson**, **Second Lesson**, and **Collect of the Day**) automatically and seamlessly use **Browser Speech Synthesis** with your selected Minister and People voices.
- If an audio file is not present, the player automatically and transparently falls back to Speech Synthesis, ensuring playback is never interrupted.

- `te-deum.mp3` — Te Deum Laudamus
